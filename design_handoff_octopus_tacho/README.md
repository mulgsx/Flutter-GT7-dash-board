# Handoff: GT7 Octopus Tachometer Dashboard

## Overview

GT7（Gran Turismo 7）のテレメトリデータをリアルタイムで受信・表示する、タコ（蛸）キャラクターを使ったタコメーターUIです。
PlayStation 5からUDP経由でテレメトリパケットを受信し、エンジンRPMをかわいいタコのくちばしが針として回転するメーターで表示します。

## About the Design Files

`GT7 Octopus Dashboard v2.html` は **高忠実度（hifi）のデザインリファレンス** として作成されたHTMLプロトタイプです。
このファイルをそのまま本番コードに使うのではなく、**既存のFlutterコードベース**（`mulgsx/Flutter-GT7-dash-board` リポジトリ）の中で、このデザインを忠実に再現することがタスクです。

既存のFlutterアプリのアーキテクチャ（`ValueNotifier` / `ValueListenableBuilder` パターン）と `GT7TelemetryService` をそのまま活用してください。

## Fidelity

**High-fidelity（高忠実度）** — 色、タイポグラフィ、アニメーション、インタラクションすべて最終デザイン済みです。可能な限りピクセルパーフェクトに再現してください。

## Tachometer: 各コンポーネント詳細

### ゲージアーク

- **角度範囲：** 135°（0 RPM、左下/7時半）→ 405°=45°（最大RPM、右下/4時半）時計回りに270°スイープ（頂点12時を経由）
- **角度計算式：** `angle = 135 + (rpm / maxRpm) * 270`（SVG度数）
- **MAX_RPM:** 9000
- **REDLINE:** 7200 RPM
- **REV_LIMIT:** 8800 RPM
- **ゲージ外径：** 196px（SVG座標）
- **トラック半径：** 186px（= GAUGE_R - 10）
- **トラック幅：** 16px（stroke-width）
- **通常域：** 0〜REDLINE をシアン `#22d3ee` で塗りつぶし
- **レッドゾーン：** REDLINE〜REV_LIMIT を `#ef4444` で塗りつぶし＋点滅アニメーション（0.2秒）
- **レッドゾーン薄いBG：** 常に薄い `#4a0808` で表示

### 目盛り・ラベル

- **大目盛り（1000 RPM毎）：** 長さ24px、幅2.5px
- **小目盛り（500 RPM毎）：** 長さ12px、幅1.2px
- **ラベル：** ゲージ外径から40px内側、0〜9（×1000 RPM）
- **7000 RPM以上：** 赤 `#f87171`

### タコの身体

#### 頭（Head）
- **形状：** 円、半径70px
- **中心：** SVG座標 (250, 218)
- **グラデーション：** ラジアル、中心から外へ明→暗

#### 触手（Tentacles）— 8本、全て下向き
SVG角度（90°=真下）で以下の角度に配置：

| 番号 | 角度 | 長さ | カール方向 |
|------|------|------|---------|
| 1 | 32° | 86px | 右 |
| 2 | 48° | 94px | 左 |
| 3 | 65° | 100px | 右 |
| 4 | 82° | 104px | 左 |
| 5 | 99° | 104px | 右 |
| 6 | 116° | 100px | 左 |
| 7 | 133° | 94px | 右 |
| 8 | 149° | 86px | 左 |

- **太さ：** 22px（stroke-width）、両端丸め（strokeLinecap="round"）
- **カーブ：** 3次ベジェ曲線。垂直方向±20pxのS字カーブ
- **先端カール：** 各触手の先端に小さなカール（14px幅、70°方向に22px）
- **スポット（吸盤）：** t=0.28, 0.54, 0.78 の位置に半径9pxのオレンジ円
- **アニメーション：** 各触手が異なる周期（1.4〜2.7秒）でゆらゆら揺れる

#### くちばし針（Beak Needle）
針はCSS回転ではなく、**各フレームで角度から座標を計算**して描画する（SVGのtransformOrigin問題を回避）。

- **ピボット：** ゲージ中心 (CX, CY) = (250, 218)
- **先端半径：** 170px
- **形状：** 二次ベジェ曲線による扁平コーン（上側・下側の2パス）
- **基部幅：** ±17px（垂直方向）
- **中間膨らみ：** 55%地点で±29px（外側にふくらむ）
- **色（通常）：** `#f0921a`（先端グロー付き）
- **色（レッドライン）：** `#fca5a5`
- **カウンターウェイト：** 中心から-30px位置に半径13pxの円

#### 顔（Face Front）— くちばしの上に描画
レイヤー順（下から）：
1. 触手
2. 頭の背景円（グラデーション）
3. くちばし針
4. 口リング → 目・眉毛（最前面）

**眉毛**
- 位置：目の上、左右対称
- 形状：二次ベジェ曲線（緩やかなアーチ）
- 高RPM（>70%）で上方向に最大16px上昇
- 色：`#6a0808`、太さ4px

**目**
- 左目：(CX-24, CY-26)、半径16px
- 右目：(CX+24, CY-26)、半径16px
- 色：`#140404`
- **瞳孔：** 半径9px、RPM方向に最大±5px追従（目がくちばし針を見る）
- **ハイライト（大）：** 半径4.5px、白、不透明度0.9
- **ハイライト（小）：** 半径2px、白、不透明度0.45
- **まばたきアニメーション：** scaleY 1→0.05→1（4秒周期、左右で0.07秒ずれ）

**ほっぺ（Blush）**
- 4000 RPM以上で出現
- 左：(CX-42, CY-8)、右：(CX+42, CY-8)、半径14px
- 色：`#f87171`、ブラーフィルタ付き
- 不透明度：`(rpm - 4000) / 5000 * 0.5`（最大0.5）

**口リング**
- 位置：(CX, CY) = くちばしのピボットと同じ位置
- 外径：半径20px、色 `#c04820`、ストローク `#7a1c06` 2px
- 内側暗部：半径12px、色 `#3a0804`
- 口から針が突き出るように見えるレイヤー順が重要

## Interactions & Behavior

### RPM針のアニメーション
- 各フレーム（rAF）で角度を再計算して描画
- CSS transitionではなくJSで毎フレーム座標を更新
- 更新レート：requestAnimationFrame（≈60fps）

### レッドライン時のエフェクト
- ゲージアーク：赤点滅（opacity 1→0.6、0.2秒）
- タコの頭：赤くなる（グラデーション変更）
- くちばし：`#fca5a5` に変色
- 画面全体：薄い赤ビネット（radial-gradient）が点滅

### 高RPM時の表情変化
- 眉毛が上がる（7000 RPM以上）
- ほっぺが赤くなる（4000 RPM以上）

## State Management（Flutter実装時）

既存の `GT7TelemetryService` を使用：

```dart
// 使用するNotifier
service.rpmNotifier        // double: エンジンRPM (0x3C)
service.isListeningNotifier // bool: 受信中かどうか
service.statusNotifier      // String: 接続状態

// GT7Packetから取得
packet.engineRPM  // double
```

タコメーターWidgetは `ValueListenableBuilder<double>` でrpmNotifierを監視し、RPM値が変化するたびに再描画します。

## 実装上の注意点

### SVG角度系
- SVG座標は **y軸が下向き**
- `90°` = 真下（時計6時方向）
- `0°` = 右（時計3時方向）
- ゲージは `135°` 始点（左下/7時半）から時計回りに `270°` スイープ

### くちばし針の描画
CSSの `transform: rotate()` をSVGの `<g>` に使うと `transformOrigin` の扱いが複雑になるため、**毎フレームで三角関数から座標を直接計算**する方式を採用。

```
tipX = CX + NEEDLE_R * cos(angle)
tipY = CY + NEEDLE_R * sin(angle)
baseLeft  = CX ± bw * cos(angle+90°)
baseRight = CX ∓ bw * cos(angle+90°)
```

### Flutter実装での代替
Flutter/Dartでは `CustomPainter` + `Canvas.drawPath()` を使用。
`canvas.save()` / `canvas.rotate()` でのアプローチも可能。
